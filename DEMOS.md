# Online demos

> **These demos have moved.** Every ZoBlocks example now lives on its component's
> page at [zoblocks.design](https://zoblocks.design/components). Each example has
> its own **Open in StackBlitz** button, which opens exactly that example running
> the same component source `zoblocks add` installs. Nothing is cloned from this
> repository.
>
> The folders under `demos/` are kept for reference and are no longer updated.
